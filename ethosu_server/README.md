# Ethos-U55 Inference Server

This directory contains a Zephyr application for the Cortex-M55 core on the Infineon PSoC Edge E84. It provides a headless inference service that receives model operations from a Cortex-M33 loader over shared SOCMEM and uses Infineon ML Middleware, TensorFlow Lite Micro, and the Ethos-U55 driver.

The M33 loader starts and configures the CM55 and U55, then sends model and input data through the shared mailbox. This application initializes the ML runtime, opens and invokes models, and returns inference results and profiling data. Operators generated by Vela for Ethos-U can execute on the Ethos-U55; other model operations run in the CM55 software runtime.

## Architecture

```text
PSoC Edge E84

+-----------------------------+       +-------------------------------+
| Cortex-M33 Secure           |       | Cortex-M55 Non-Secure         |
|                             |       |                               |
| Arduino sketch              |       | This Zephyr application       |
|       |                     |       | ethos_server                   |
|       v                     |       |       |                       |
| Ethos-U remote API          |       | Infineon ML Middleware        |
|       |                     |       | TensorFlow Lite Micro          |
| M33 loader                  |       |       | Vela Ethos-U operator |
| starts CM55/U55 and posts   |       |       v                       |
| model/input requests        |       | Ethos-U driver                |
+-------------+---------------+       +---------------+---------------+
              |                                       |
              | model, input, command                |
              v                                       v
       +------+---------------------------------------+------+
       | Shared SOCMEM mailbox and data slots                 |
       | 0x26200000, 2 MiB                                   |
       +------------------------------------------------------+
                                                       |
                                                       v
                                             +--------------------+
                                             | Ethos-U55-128 NPU  |
                                             +--------------------+
```

## Files

| File | Purpose |
| --- | --- |
| `src/main.c` | Implements the mailbox service, model lifecycle, inference dispatch, cache maintenance, heartbeat, and profiling updates. |
| `CMakeLists.txt` | Defines the Zephyr application, includes the shared IPC header, and configures the U55 power-helper link wrapper. |
| `prj.conf` | Enables the CM55 C++ runtime, dynamic interrupts, Infineon ML Middleware, the TFLite interpreter, INT8 support, and Ethos-U55 backend; disables unused console/peripheral services. |
| `boards/kit_pse84_ai_pse846gps2dbzc4a_m55.overlay` | Disables shared peripherals reserved for the CM33 loader and its console. |
| `../loader/ethosu_ipc.h` | Defines the mailbox protocol and shared model/input/output slot layout used by both cores. |

## Build

Build this application from the configured Zephyr workspace with the PSoC Edge E84 M55 board target:

```sh
west build -p -d build/ethosu_server \
  -b kit_pse84_ai/pse846gps2dbzc4a/m55 \
  --no-sysbuild <path-to-ArduinoCore-zephyr>/ethosu_server
```

The build produces `build/ethosu_server/zephyr/zephyr.hex`. The image is intended for the CM55 XIP region at `0x60500000` and must be programmed separately from the CM33 loader and Arduino sketch. Install a matching CM33 loader that starts the CM55 and uses the same mailbox ABI before running this service.
